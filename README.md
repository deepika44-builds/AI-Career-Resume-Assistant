# AI Career & Resume Assistant

An AI-powered career assistance tool built using Python and Google's Gemini API. It helps students analyse resumes, compare job descriptions, identify skill gaps, and prepare for interviews.

## Features

- **Resume Analyzer:** Analyses PDF resumes and provides feedback, strengths, missing skills, and improvement suggestions.
- **Job Description Matcher:** Compares a resume with a job description and identifies matching and missing skills.
- **Skill Gap Analyzer:** Identifies skills to improve and generates a learning roadmap.
- **Interview Preparation:** Generates technical, programming, project-based, and HR interview questions.

## Technologies Used

- Python
- Google Gemini API
- Google Colab
- PyPDF

## How to Run

1. Open the notebook in Google Colab.
2. Add your Gemini API key to Colab Secrets using the name `GEMINI_API_KEY`.
3. Enable notebook access to the secret.
4. Run the notebook cells in order.
5. Upload a PDF resume when prompted.

## Project Purpose

This is an independent educational project designed to explore practical applications of generative AI in career development.
